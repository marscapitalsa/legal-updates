# Mars Capital Regulatory Brief

A front-end prototype for a Swiss legal and regulatory intelligence service for asset managers.

The demonstration presents concise, editorial-style updates across FINMA supervision, AML, sustainable finance, FIDLEG and governance. The displayed updates are illustrative placeholders; source monitoring and alerting will be added in a later phase.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
