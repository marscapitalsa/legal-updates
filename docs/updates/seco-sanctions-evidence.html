SAM July Newsflash · Association recommendation

SECO search results can no longer be printed or saved as before

What changed: SAM reports that the former function for directly printing or saving a SECO sanctions-search result is no longer available. SECO is examining whether to reintroduce it. [S1, “SECO sanctions search”]

Action plan

Applicability
Sanctions
Relevant if the IAM relies on manual searches in SECO's online tool and previously retained the tool's print or save output. [S1]
Responsible person / function
Proposed internal allocation:
Primary execution: outsourced AML Officer / compliance function
Internal accountable owner: Director designated for AML oversight. Legal escalation: in-house Legal Counsel. Procedure approval and oversight: Directors. [S3] [S4]
Due / trigger
No external deadline stated. Internal procedure date: to be set. Use the replacement evidence method when the next relevant manual search is performed.
Status
Check procedure
  • Check whether the IAM's procedure depends on the removed print/save function.
  • If it does, use software or a browser extension to make a screenshot that records the search date and time, as SAM recommends. [S1]
Evidence
A date- and time-stamped screenshot of the search result. [S1]

What matters

  • SAM reports both the loss of the print/save function and the recommended screenshot solution. [S1]
  • The SECO search is a supporting tool; SECO does not determine how a financial intermediary fulfils its due-diligence duties. [S1]
  • SECO's page remains the official entry point for searching sanctioned subjects. [S2]
