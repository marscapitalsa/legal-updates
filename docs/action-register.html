Weekly supervision cycle

  1. New publication is assessed for applicability and action type.
  2. A topic page and action-plan row are created.
  3. The accountable function confirms the owner, deadline and internal task location.
  4. Calendar reminders are set outside the public site, normally including a one-week advance reminder.
  5. Before the Monday call, open and overdue items are reviewed.
  6. Completion is accepted only when the stated evidence exists; internal evidence is not uploaded here.

Status vocabulary: Review required — decision or gap assessment pending; Ongoing — recurring control; Monitor — no present implementation until a trigger occurs.
