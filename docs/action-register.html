Weekly supervision cycle

  1. Assess each development for applicability and required action.
  2. Create a topic page and action plan where implementation is needed.
  3. Assign the internal owner, deadline and required evidence.
  4. Review open items before the weekly call.
  5. Close an item only when the required evidence exists.

Potentially relevant topics without a current implementation requirement remain in the brief rather than the action register.
